# Produktbilder

Lege hier deine eigenen Original-Produktfotos ab (am besten freigestellte PNGs oder WebPs,
quadratisch, ca. 800×800 px, transparenter Hintergrund).

Danach in `products.js` beim jeweiligen Produkt den Pfad eintragen:

```js
{ id: 'ice-mint-8', flavor: 'ice-mint', strength: 2, price: 5.49, image: 'assets/products/ice-mint-8.png' },
```

Produkte ohne `image` bekommen automatisch eine gerenderte 3D-Dose in der Sortenfarbe.

**Wichtig:** Verwende nur Bilder, an denen du die Rechte hast (eigene Fotos oder vom Hersteller
für Händler freigegebenes Pressematerial). Fotos und Logos von Marken wie Pablo oder Iceberg sind
urheber- und markenrechtlich geschützt.
