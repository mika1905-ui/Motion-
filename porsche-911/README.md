# 911 Turbo S (992) — motion piece

A 17.5 s screen-motion film in the style of the reference clip: light streaks → badge burst →
"My 911 Garage" → chat configuration → paint configurator → 650 PS / 0–100 in 2.7 s →
test-drive booking → "Your 911, in one sentence." model picker → logo outro.

* `index.html` — the whole animation, driven by `renderAt(t)` (deterministic, seekable).
  Open it in a browser to watch it loop live.
* `assets/` — the 992 Turbo S photo (Python Green) plus Shark Blue, Guards Red and Carrara White
  variants generated by `scripts/recolor.py`.
* `scripts/render.js` — Playwright frame capture at 1920×1080.
* `scripts/sound.py` — synthesised sound bed (whooshes, hits, UI ticks), no samples.
* `scripts/build.sh` — renders everything to `out/911-motion-16x9.mp4` and a vertical
  `out/911-motion-9x16.mp4`.

To use official press/CGI images: drop them into `assets/` with the same file names
(`911-<paint>.jpg`, 3:1 crop works best) and run `scripts/build.sh`.
