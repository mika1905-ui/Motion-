# FLUXE Studio – Logo

Bildmarke: drei fließende Balken – abstraktes „F“, Bewegungsspur und Equalizer in einem (Motion · Sound · Flow).
Farbe: Lime `#d4ff3a` mit Verlauf, Hintergrund `#08080a`. Schrift: Inter Display Black / SemiBold.
